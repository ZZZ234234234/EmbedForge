# DHT11 单总线驱动要点

## 关键时序（数据手册值，uS 级）
1. 主机起始：数据线拉低 **≥18ms**，再拉高 **20~40us** 后释放（切输入）。
2. DHT 响应：拉低 80us + 拉高 80us；等不到响应要超时退出并返回错误。
3. 数据位："0" = 低 50us + 高 26~28us；"1" = 低 50us + 高 70us。**以高电平宽度区分 0/1**，阈值取 50us。
4. 40bit 数据 = 湿度整数 + 湿度小数 + 温度整数 + 温度小数 + 校验和（前四字节之和低 8 位）。

## 必须处理的工程问题
- **两次读取间隔 ≥1~2s**（传感器内部转换周期），读快了返回 40bit 全 0 或校验失败。
- 微秒延时必须用 DWT/定时器，`HAL_Delay` 只有 ms 精度根本测不了位宽。
- 读位过程中**关闭中断**（或临界区），SysTick 抖动会把 70us 的高电平测成 90us 导致 0/1 误判。
- 数据线必须 **4.7k~10kΩ 上拉**，线长 >20m 时降速并加缓冲。
- 校验失败要丢弃整帧并计数，连续 N 次失败进入传感器离线告警，不要拿脏数据刷新显示。
- DHT22（AM2302）负温处理：温度高字节的 bit8 是符号位，直接当无符号解析冬天全是正温。

## 接口设计建议
```c
typedef enum { DHT_OK = 0, DHT_ERR_TIMEOUT, DHT_ERR_CHECKSUM } dht_status_t;
dht_status_t dht11_read(float *temp_c, float *rh_percent);  // 内部自带时序与校验
```
