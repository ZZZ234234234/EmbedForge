# 嵌入式代码审查清单（资深视角）

## 编译与链接（最低门槛）
- 头文件 include guard 齐全；无重复定义；`static` 修饰内部函数/变量。
- 无隐式声明、无未使用变量告警；开启 `-Wall -Wextra` 应基本干净。
- 中断向量名与启动文件一致（HAL 的 `xxx_IRQHandler` 拼错 = 静默不进中断）。

## 硬件交互正确性
- 引脚/时钟/复用配置与规划表一致；外设时钟已使能。
- 时序参数（us 级延时、建立保持时间）有依据，微秒延时实现可靠（DWT/定时器）。
- 上拉/开漏/推挽/速度等级与电气需求匹配。

## 中断与并发
- ISR 共享变量 `volatile`；多字节共享数据有临界区。
- ISR 内无延时、无 printf、无 malloc、无非 FromISR 的 RTOS 调用。
- NVIC 优先级分组显式配置，关键中断不被抢占饿死。

## 鲁棒性
- 所有 HAL/驱动调用检查返回值；总线操作带超时，失败路径明确（重试/降级/告警）。
- 缓冲区边界检查（数组/环形队列），字符串操作用 snprintf。
- 看门狗已启用且喂狗策略能暴露单任务卡死。
- 主循环结构是状态机/调度器，无裸奔 `while(1)+delay` 硬延时业务逻辑。

## 可维护性
- 驱动与应用分层，接口在头文件声明并带注释。
- 魔数提取为具名宏（寄存器地址、超时时间、阈值）。
- 无注释掉的死代码、无调试 printf 残留（或用日志级别宏控制）。
